# Текущий UI — проект EDT 2026.2

Проверено по `plugin.xml`, `StorageSettingsDialog`, `FullStorageReviewHandler`, `OutgoingReadinessHandler` на `931c846`. Это **описание кода**, не доказательство безошибочной работы установленного плагина.

## Вход

Контекстное меню **проекта EDT** → «Работа с хранилищем» (отдельное окно, настройки именно этого проекта). В группе команд также существуют «Полная сверка с хранилищем», «Проверить возможность помещения в хранилище» и диагностика проекта (конкретный русский текст ресурсов — `plugin_ru.properties`).

## Параметры окна

- Адрес, пользователь, пароль **классического хранилища**.
- Тип базы-посредника **файловая / серверная**, её путь или /S адрес, отдельный пользователь и пароль **ИБ**.
- Путь к установленному исполняемому файлу `1cv8.exe`.
- Последняя **наблюдаемая** версия хранилища и версия, которую интерфейс показывает как рассмотренную/«применённую»; в коде различаются `REVIEWED` и строгий `APPLIED`, не выдавать подпись за эквивалентность.
- Кнопка **«Проверить версию хранилища»** запускает чтение штатного отчёта без обновления проекта.
- **«Очистить историю получения…»** запускает архивирующее восстановление локального состояния после подтверждения. Это не обновляет ИБ и не отменяет неизвестную native операцию.

## Действия

- **«Получить изменения»** — `ReceiveMode.INCREMENTAL`, выборочная подготовка и нативный EDT Merge.
- **«Полная сверка с хранилищем»** — `ReceiveMode.FULL_REVIEW`, полноценная XML выгрузка и глобальное нативное сравнение (явное действие).
- **«Проверить возможность помещения в хранилище»** — исходящий preflight + read-only сравнение, экспорт и превью; последующий TEST-ONLY путь Lock/Load/Commit требует дополнительных строгих подтверждений и допустим лишь на тестовой копии.
- **«Сохранить» / «Отмена»** — работа с настройками, а не доказательство применения изменений.

## Важные различия

В существующем проекте EDT могут быть подключены свои тестовые/рабочие базы; это **не** база-посредник плагина. Наличие Git-коммита не означает помещение в классическое хранилище. Внешний xml import ≠ применение в EDT. Полное сравнение ≠ «полностью применено» без отдельной проверки.
