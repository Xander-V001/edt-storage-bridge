# ADR 0002: Make 1C:EDT 2026.2 the only primary target

Date: 2026-10-16
Status: accepted by project owner
Supersedes: [ADR 0001](0001-initial-stack.md) for all future builds

## Decision

- Target 1C:EDT product series **2026.2**, not 2026.1.
- Use Eclipse IDE **2025-12**, Java **25** (including compiler bytecode), Tycho **5.0.2**, pinned Maven **3.9.9**.
- Resolve 1C bundles from the vendor-supplied `https://edt.1c.ru/downloads/releases/ruby/2026.2/` target. Do not vendor 1C binaries.
- Introduce separate `edt` API adapter; keep the core free from EDT, Eclipse UI and Git concerns.
- Access documented `IConfigurationProvider` as a public OSGi service, supplied using vendor-recommended Guice factory.
- Do not assume that the older, tested Eclipse-only p2 artifact works with EDT 2026.2.
- Build and test **only when specifically requested**; not after source commits.

## Consequences

- The old Eclipse 2024-06 target was removed from the active reactor and from the feature branch.
- A 2026.2 manual build and an EDT 2026.2 smoke test are outstanding. Source code is not yet a release.
- In case of vendor p2 auth requirements or missing dependencies, do not bypass these by embedding binaries or accessing private APIs. Resolve supported dependencies openly, record limitations, and ask for required credentials setup without collecting them in chat.
