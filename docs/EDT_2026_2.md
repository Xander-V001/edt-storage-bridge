## Implemented sources (not yet compiled against 2026.2)

- `targets/edt-2026.2/edt-2026.2.target` uses the official 2026.2 p2 base and Eclipse 2025-12. It is intentionally a smaller target than the 1C demo and is **not yet proven resolvable**; if the dependency closure is incomplete, resolve it according to the official target rather than adding arbitrary bundles.
- Java 25 execution environment for the three plugin bundles and OSGi tests; Maven Tycho 5.0.2.
- `org.xander.edt.storagebridge.edt.EdtProjectInspector` is the read-only adapter around the documented `IConfigurationProvider`.
- `BridgeServiceModule`, `BridgeActivator`, `BridgeExtensionFactory` use the documented Guice / Eclipse extension mechanism.
- `InspectProjectHandler` runs model inspection in a background Eclipse Job. No repository operations, no file export and no model writes.

## Not verified

1. The currently installed EDT **exact patch/build** and its p2 bundle versions.
2. Whether the current CI runner can resolve the 2026.2 target without an IТS account; do not assume it can.
3. Bytecode/API compatibility of the newly written integration module and the Eclipse extension handler.
4. Runtime thread requirements for reading a model from the background Job.
5. p2 installation into a clean EDT 2026.2 instance.

These require **one explicitly requested manual build** and **manual smoke testing**, separately. Prior successful builds against the Eclipse 2024-06 baseline are not evidence of EDT 2026.2 compatibility.

## Manual smoke-test matrix (when requested)

- EDT 2026.2 installed; command appears once in workbench menu.
- No selection: explain that a project must be selected.
- Non-project selection or closed project: safe diagnostic, no exception dialog.
- EDT configuration project: display project location and model availability.
- Extension/non-V8 project: show the factual outcome without incorrectly identifying a project type.
- Long model load or canceled job: UI remains interactive; no writes are performed.
- Close view/workbench before job completion: no SWT thread error.
- Check Error Log for service-resolution or job failures; do not expose credentials.

## Platform version is not the EDT version

`1C:EDT 2026.2` is the **IDE product version**. Supported runtime versions `8.3.x`/`8.5.x` are separate. Do not equate 8.3.27.2202 (a runtime baseline for some features in 2026.2) with the target IDE patch version.
