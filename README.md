# EDT Storage Bridge

Независимый плагин для **1C:Enterprise Development Tools (EDT) 2026.2**, предназначенный для безопасного обмена с классическим хранилищем конфигурации 1С.

> **Статус: разработка, ещё не релиз.** Реальный обмен с хранилищем не реализован. Текущая ветка 2026.2 требует отдельной проверки компиляции и установки в EDT.

## Технологии

- **Цель:** EDT 2026.2 (Eclipse 2025-12, Java 25).
- Java 25 / Eclipse PDE / OSGi / Maven Tycho 5.0.2.
- Отдельные bundles: `core` (логика и проверки), `edt` (публичный API 1C:EDT), `ui` (интерфейс).
- Maven + GitHub Actions **только по ручному запуску** — коммиты и PR ничего не собирают.
- Eclipse p2 для установки (будущие релизы и ZIP).

## Что реализовано в исходниках

Команда `EDT Storage Bridge → Inspect selected project`: определяет выделенный workspace-проект, обращается к публичному сервису EDT `IConfigurationProvider` **только для чтения**, выводит наличие модели конфигурации и локальный путь. Операция модели исполняется в фоновом Job, окно результата — в SWT UI-потоке.

Код этой команды на EDT 2026.2 **ещё не собирался и не тестировался**. Предыдущая успешная сборка относилась к прототипу Eclipse, не являлась тестом совместимости с EDT 2026.2.

## Приоритеты

1. Проверяемая совместимость с EDT 2026.2 без внутренних API и рефлексии.
2. Полная изоляция изменений от рабочего хранилища и информационных баз.
3. Чёткое разделение Git / EDT / 1С-хранилища / промежуточной базы.
4. Явная проверка результата каждой операции и журнал, пригодный для диагностики.
5. Оптимизация после реальных замеров, а не преждевременная параллелизация.
