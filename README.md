# EDT Storage Bridge

Независимый плагин для **1C:Enterprise Development Tools (EDT)**, предназначенный для безопасного обмена изменениями с классическим хранилищем конфигурации 1С.

> **Статус: ранняя разработка (prototype).** Обмен с хранилищем пока не реализован. Не устанавливайте прототип вместо рабочего инструмента.

## Приоритеты

- Безопасность данных и предсказуемые транзакции синхронизации.
- Независимость от конкретной системы контроля версий: интеграция с Git — дополнительный компонент.
- Наблюдаемость: каждый этап получает статус, длительность и диагностическую информацию.
- Выборочное получение и помещение объектов только после подтверждения корректности штатных механизмов 1С.
- Установка через стандартный Eclipse p2-репозиторий.

## Технологии

Java / Eclipse PDE / OSGi / Maven Tycho / GitHub Actions. Первый прототип ограничен API Eclipse Platform и не изменяет проекты и хранилища. Специфичные API EDT будут вводиться после проверки совместимости и доступности target platform.

## План

1. Минимальный устанавливаемый плагин с командой проверки выбранного проекта.
2. Контракты и тесты движка синхронизации; read-only диагностика подключения.
3. Получение изменений на тестовом хранилище с проверкой версий и конфликтов.
4. Помещение изменений и подтверждение записи в хранилище.
5. Производительность, устойчивость к сбоям и стабильные обновления.

Подробности — в `docs/` и задачах GitHub Issues.

**Никаких операций записи с продуктивными базами или хранилищами на этапе прототипа.**
